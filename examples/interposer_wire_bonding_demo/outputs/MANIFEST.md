## layout/ (GDS layouts and their sidecars)

The .chiplet references the interposer GDS by a `layout/<file>` path, resolved against the .chiplet's own directory. The boundary and interconnect-method sidecars travel with their GDS so the assembly DRC finds them as siblings.

- [x] `layout/interposer_wire_bonding_demo_interposer.gds` - interposer layout (referenced by the .chiplet)
- [x] `layout/interposer_wire_bonding_demo_interposer.boundaries.json` - chiplet-boundary manifest for the interposer GDS
- [ ] `layout/interposer_wire_bonding_demo_complete.gds` - full assembly layout (interposer + dies)
- [x] `layout/interposer_wire_bonding_demo_complete.boundaries.json` - chiplet-boundary manifest for the complete GDS
- [x] `layout/interposer_wire_bonding_demo_complete.ixn_methods.json` - per-method interconnect scoping sidecar for the assembly DRC
